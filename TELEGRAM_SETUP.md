# Настройка Telegram для формы обратной связи

## Быстрая настройка (5 минут)

### 1. Создайте бота

1. Откройте Telegram
2. Найдите бота **@BotFather**
3. Отправьте команду `/newbot`
4. Придумайте имя бота (например: `PetAirlinesFeedback`)
5. Придумайте username (например: `pet_airlines_feedback_bot`)
6. **Скопируйте токен** (выглядит так: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Получите Chat ID

**Вариант 1 (простой):**
1. Найдите бота **@userinfobot** в Telegram
2. Отправьте ему любое сообщение
3. **Скопируйте ваш ID** (это число, например: `123456789`)

**Вариант 2 (через бота):**
1. Отправьте любое сообщение вашему новому боту
2. Откройте в браузере: `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
3. Найдите `"chat":{"id":123456789}` и скопируйте этот ID

### 3. Настройте переменные окружения

Создайте файл `.env` в корне проекта:

```bash
VITE_TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
VITE_TELEGRAM_CHAT_ID=123456789
```

### 4. Перезапустите dev сервер

```bash
npm run dev
```

Готово! Теперь сообщения из формы будут приходить вам в Telegram 🎉

## Для production

При деплое (Vercel, Netlify и т.д.) добавьте эти переменные в настройках проекта:
- `VITE_TELEGRAM_BOT_TOKEN`
- `VITE_TELEGRAM_CHAT_ID`

## Dev режим

Без настройки Telegram форма работает в dev режиме - сообщения выводятся в консоль браузера.
