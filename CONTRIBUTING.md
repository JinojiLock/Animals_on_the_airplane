# 📝 Руководство по добавлению данных

## Добавление новой авиакомпании

### 1. Откройте файл с данными
Файл находится по пути: `src/data/airlines.json`

### 2. Структура записи

```json
{
  "id": "unique-airline-id",
  "name": "Название авиакомпании",
  "logo": "🛫",
  "transportMethods": ["cabin", "baggage", "cargo"],
  "conditions": {
    "cabin": {
      "maxCarrierSize": "55x40x25 см",
      "maxWeight": "8 кг",
      "allowedAnimals": ["собаки", "кошки", "птицы"],
      "additionalInfo": "Дополнительная информация"
    },
    "baggage": {
      "maxCarrierSize": "до 203 см в сумме",
      "maxWeight": "до 23 кг",
      "allowedAnimals": ["собаки", "кошки"],
      "additionalInfo": "Переноска должна быть прочной"
    },
    "cargo": {
      "maxCarrierSize": "без ограничений",
      "maxWeight": "без ограничений",
      "allowedAnimals": ["любые виды"],
      "additionalInfo": "Оформляется через карго-отдел"
    }
  },
  "rulesUrl": "https://airline.com/rules/pets"
}
```

### 3. Описание полей

#### Обязательные поля:

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | Уникальный идентификатор (латиница, без пробелов) |
| `name` | string | Название авиакомпании |
| `transportMethods` | array | Массив доступных способов перевозки |
| `conditions` | object | Объект с условиями для каждого способа |
| `rulesUrl` | string | URL официальных правил авиакомпании |

#### Необязательные поля:

| Поле | Тип | Описание |
|------|-----|----------|
| `logo` | string | Эмодзи или символ для логотипа |

### 4. Способы перевозки (transportMethods)

Возможные значения:
- `"cabin"` - в салоне самолета
- `"baggage"` - в багажном отделении
- `"cargo"` - карго (грузовой отсек)

### 5. Условия перевозки (conditions)

Для каждого способа перевозки можно указать:

```json
{
  "maxCarrierSize": "размеры переноски (ШxВxГ)",
  "maxWeight": "максимальный вес",
  "allowedAnimals": ["список", "допустимых", "животных"],
  "additionalInfo": "любая дополнительная информация"
}
```

Все поля внутри `conditions` необязательны, указывайте только доступную информацию.

### 6. Пример полной записи

```json
{
  "id": "turkish-airlines",
  "name": "Turkish Airlines",
  "logo": "🇹🇷",
  "transportMethods": ["cabin", "baggage"],
  "conditions": {
    "cabin": {
      "maxCarrierSize": "42x32x28 см",
      "maxWeight": "8 кг (вместе с контейнером)",
      "allowedAnimals": ["кошки", "собаки до 8 кг", "птицы"],
      "additionalInfo": "Контейнер должен размещаться под сиденьем"
    },
    "baggage": {
      "maxCarrierSize": "максимум 127 см в сумме трех измерений",
      "maxWeight": "до 32 кг",
      "allowedAnimals": ["собаки", "кошки"],
      "additionalInfo": "Бронирование требуется за 48 часов до вылета"
    }
  },
  "rulesUrl": "https://www.turkishairlines.com/en-int/any-questions/travel-with-pet/"
}
```

### 7. Добавление записи в файл

1. Откройте `src/data/airlines.json`
2. Добавьте запятую после последней записи
3. Вставьте новую запись
4. Сохраните файл
5. Убедитесь, что JSON валидный (можно проверить на https://jsonlint.com/)

### 8. Проверка

После добавления:
1. Запустите `npm run dev`
2. Откройте приложение в браузере
3. Найдите новую авиакомпанию в списке
4. Проверьте корректность отображения всех данных

### 9. Где искать информацию

Официальные источники для сбора данных:
- Официальный сайт авиакомпании (раздел "Правила перевозки животных")
- Официальные правила и условия
- Служба поддержки авиакомпании

⚠️ **Важно**: Всегда указывайте ссылку на официальные правила в поле `rulesUrl`!

### 10. Советы

- **ID**: используйте kebab-case (например: `lufthansa`, `air-france`)
- **Эмодзи**: можно использовать флаги стран 🇷🇺🇺🇸🇬🇧 или авиа-символы ✈️🛫🛬
- **Размеры**: указывайте в понятном формате (ШxВxГ см)
- **Вес**: указывайте единицы измерения (кг)
- **Животные**: перечисляйте конкретные виды
- **Дополнительно**: краткая, но важная информация

## Обновление существующей записи

1. Найдите запись по `id` в файле `src/data/airlines.json`
2. Обновите необходимые поля
3. Сохраните файл
4. Проверьте изменения в браузере

## Удаление записи

1. Найдите запись по `id` в файле `src/data/airlines.json`
2. Удалите весь объект вместе с запятыми
3. Убедитесь, что JSON остался валидным
4. Сохраните файл
