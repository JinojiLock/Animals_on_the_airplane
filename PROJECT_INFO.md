# 📊 Информация о проекте

## 🎯 Назначение

**Pet Airlines Directory** - веб-приложение для поиска информации о правилах перевозки животных различными авиакомпаниями.

## ✨ Ключевые особенности

### Функциональность
- ✅ Карточки с информацией по 6 российским авиакомпаниям
- ✅ Фильтрация по способу перевозки (салон, багаж, карго)
- ✅ Поиск по названию авиакомпании
- ✅ Адаптивный дизайн (мобильные, планшеты, десктоп)
- ✅ Детальная информация по условиям перевозки
- ✅ Прямые ссылки на правила авиакомпаний

### Технические особенности
- 🏗️ **Архитектура**: Модульная структура с разделением ответственности
- 🔄 **Масштабируемость**: Интерфейс IDataService для легкой миграции на БД
- 📱 **UI/UX**: Современный интерфейс на Tailwind CSS
- ⚡ **Производительность**: Быстрая сборка с Vite
- 📘 **Типизация**: Полная типизация TypeScript
- 🎣 **Hooks**: Кастомные хуки для управления состоянием

## 📦 Состав проекта

### Компоненты (5 шт.)
1. **Header** - Шапка сайта с логотипом и заголовком
2. **Filters** - Панель фильтров (способ перевозки + поиск)
3. **AirlineCard** - Карточка авиакомпании с детальной информацией
4. **Footer** - Подвал сайта с дополнительной информацией
5. **App** - Главный компонент приложения

### Сервисы
- **DataService** - Интерфейс для работы с данными
- **JsonDataService** - Реализация на основе JSON
- **useFilters** - Хук для управления фильтрами

### Типы TypeScript
```typescript
- TransportMethod: 'cargo' | 'baggage' | 'cabin'
- Airline: полная информация об авиакомпании
- TransportConditions: условия перевозки
- Filters: параметры фильтрации
```
